# Agents (agent/)

This directory contains detailed operating rules for AI agents working under the Codex Automata methodology.

Each file addresses a specific phase: specification writing, test molding (mold), code casting (casting), and review.

`AGENT_RULES.md` is the comprehensive reference. The other files provide phase-specific detail.

When working in a Codex Automata project, follow these rules strictly.

If any rule conflicts with a user instruction, surface the conflict rather than silently breaking the rule.
